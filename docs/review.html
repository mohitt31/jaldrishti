Intended user: a geology or environmental researcher preparing a note from published West Bengal arsenic/fluoride evidence. Find a measurement, inspect its scope, check a comparison, then export it for review. Practical time savings remain a hypothesis until a user pilot is completed.

Implemented · engineering checks

Input → cited evidence → reviewable note

The browser runs the Python answer engine over an exported source snapshot. Save an answer or refusal, export readable Markdown or review JSON, import the JSON, append reviewer comments, and export it again. Source measurements stay separate from comments. Imported notes can be rechecked with Python.

Evidence: workflow engineering report and browser checks, note-integrity tests.

Limit: review statements are self-reported; matching the local engine is reproducibility, not independent expert certification. Sharing is an explicit file handoff, not automatic delivery.

Implemented · source lineage

What SerpApi contributes

Google Search and Scholar harvesting supplied a reusable document library. Each supported source exposes the exact recorded engine, query and found-document relationship. Browser queries reuse that library without making a new API call. Reference scope explicitly adds separately curated reports.

Evidence: source discovery records, snapshot identities, original harvest manifest, later search overlay.

Limit: a recorded found-document relation is not proof of first discovery. Missing traces and curated-only sources are labelled. The static site does not search for fresh documents.

Frozen historical evaluation · audited limitations

Source finding changes the answer set

The original test scored library 12/20, baseline 2/20, and oracle 17/20. The library used 9 question-time searches plus 56 earlier harvest searches; baseline used 58. These are frozen historical results under the original scorer, not measured human productivity.

Evidence: frozen original report and evaluation contract.

Limit: the system author had seen the question texts; citation checks find numbers on pages, and comparison scoring can reward the right answer type with wrong rows. The later holdout audit documents such failures. Post-hoc fixes are not a new blind accuracy score.

Not evaluated with users

Does it help researchers finish their task?

No completed user sessions or independently confirmed reviewer endorsement are claimed. A formative pilot is planned against ordinary Google/PDF work, recording correctness, timeouts, time, assistance and failures.

Evidence status: proposed pilot protocol. Recruitment targets are plans, not participants or results.

Limit: student feedback must be labelled as such. Until observations exist, no percentage time savings, professional adoption or real-world validation claim is justified.

Try the distinctive check

Open the “332 vs 329 µg/L” example. Similar-looking numbers can describe a site maximum and a study mean. NeerTathya shows the failed comparison checks and retains both citations in a portable note.

Not a household safety tool. Sampling period and publication year are separate. The district map shows evidence coverage and reported values across different surveys; it is not a district risk ranking.
