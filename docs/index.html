The library SerpApi built

How it works

  1. Harvest. 69 completed Google and Google Scholar searches over generic district templates (56 original + 13 supplemental) build a library of government reports and paper abstracts. No question text is used.
  2. Read. Every table cell becomes a typed record: value, unit, statistic, place, well, date or period, spatial support, page, row.
  3. Answer or refuse. Places must exist in a table row. Comparisons are checked for the same sampling point, statistic, spatial support and time separation. Requests the sources cannot support are refused with a reason.
  4. Re-read. Before answering, each number is searched for again on the cited PDF page with a second PDF library.
  5. Fallback. If a source is missing, at most two searches including district resolution, planned from cues in the question (named study → Scholar, publisher → site filter, village → quoted place).
Ask runs Python over a saved evidence snapshot; the explorer shows historical answers. No new web search runs in this site.
