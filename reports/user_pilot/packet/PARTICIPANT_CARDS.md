# Participant task cards — pilot-v1

Show only the assigned task, not the answer key. These are tasks, not collected results.

For all tasks, the named source is CGWB **Ground Water Quality of West Bengal**, Annexure I. Use the same device and connection in both conditions. Condition A: ordinary Google search and PDF reading. Condition B: NeerTathya, **SerpApi-discovered library**, plus source PDF viewing. No generative search/chat tools in A. The facilitator records any deviation.

You may refine queries. Produce a short source-cited note in your usual text editor in either condition. Opening the supporting source is required. Native note export is optional and reviewed separately, so export speed is not mixed into the primary endpoint.

Each task has a 4-minute cap. Say “finished” when your note is ready; mistakes are useful feedback.
